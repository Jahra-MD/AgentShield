# AgentShield — MCP Authorization Proxy

AgentShield is a Python-based MCP authorization proxy that adds a human approval step before AI assistants execute tools. It allows users to approve or block tool requests through a simple popup, supports multiple requests, and automatically denies requests that time out.

It works with both **Claude Desktop** and **Claude Web**.

## Features

- Human approval before MCP tool execution
- Allow / Block authorization popup
- Supports Claude Desktop (stdio) and Claude Web (HTTP)
- Handles multiple tool requests independently
- Automatically denies requests after a 30-second timeout
- Bearer-token authentication for HTTP requests

## Available MCP Tools

### Claude Desktop — Portfolio Server

| Tool | Description |
|---|---|
| `add_numbers` | Adds two numbers |
| `get_developer_profile` | Returns developer profile information |
| `get_technical_skills` | Returns technical skills by category |
| `get_project_details` | Returns details about a project |
| `get_career_achievements` | Returns professional achievements |
| `generate_verification_code` | Generates a random verification code |

Portfolio data is stored in `demo_data/developer_profile.json`.

### Claude Web — HTTP Gateway

| Tool | Description |
|---|---|
| `gateway_health_check` | Checks gateway status |
| `generate_verification_code` | Generates a random verification code |

## How It Works

```text
Claude Desktop / Claude Web
           |
           v
       AgentShield
           |
           v
     Approval Popup
           |
     +-----+-----+
     |           |
   Allow       Block
     |           |
     v           v
 Execute Tool   Deny Request
```

## Tech Stack

Python, MCP Python SDK, Asyncio, Tkinter, Uvicorn, Cloudflare Tunnel.

## Setup

Clone the repository:

```powershell
git clone https://github.com/Jahra-MD/AgentShield.git
cd AgentShield
```

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the project dependencies using the dependency file included in the repository.

## Execution

### 1. Claude Desktop

Configure Claude Desktop to launch the AgentShield MCP proxy using the project's Python environment.

For manual startup:

```powershell
python -m agentshield.main
```

Restart Claude Desktop after configuring the MCP server.

**Example prompt:**

> Add 10 and 20 using the add_numbers tool.

An authorization popup appears. Click **Allow** to execute the tool or **Block** to deny it.

### 2. Claude Web

**Step 1 — Generate an API token**

Run in PowerShell:

```powershell
$env:AGENTSHIELD_API_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Save the token securely for reuse.

**Step 2 — Start Cloudflare Tunnel**

Open a new terminal:

```powershell
cloudflared tunnel --url http://127.0.0.1:8000
```

Copy the generated Cloudflare hostname.

**Step 3 — Start AgentShield**

In the terminal where the API token is set:

```powershell
$env:AGENTSHIELD_PUBLIC_HOST = "your-tunnel.trycloudflare.com"

python -m agentshield.web_main
```

Replace `your-tunnel.trycloudflare.com` with the hostname generated by Cloudflare.

**Step 4 — Connect Claude Web**

Go to **Settings → Connectors → Add custom connector**.

| Setting | Value |
|---|---|
| Name | AgentShield |
| URL | `https://your-tunnel.trycloudflare.com/mcp` |
| Authentication | No sign-in |
| Transport | Streamable HTTP |
| Custom Header | `Authorization: Bearer YOUR_API_TOKEN` |

Keep the AgentShield server and Cloudflare Tunnel running.

**Example prompt:**

> Use AgentShield to generate a verification code.

An authorization popup appears. If approved, Claude receives the generated code. If blocked or timed out, the tool execution is denied.

## Testing

AgentShield has been tested with Claude Desktop and Claude Web for:

- Successful tool execution after approval
- Tool rejection after blocking
- Multiple concurrent authorization requests
- Automatic denial after timeout
- HTTP Bearer-token authentication

## Limitations

The Claude Web gateway currently exposes demonstration tools, while the Desktop proxy supports tools from its configured upstream MCP server. Cloudflare Quick Tunnel URLs are temporary.
